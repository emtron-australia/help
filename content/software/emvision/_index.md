EmVision is Emtron's log analysis application. Open logs from displays and ECUs, compare laps, build custom plot layouts, and create math channels.

New to EmVision? Start with [Getting Started](getting-started). See [EmVision Features](emvision-features) for a full capabilities list, or the [EmVision User Guide](emvision) for menus and layout overview.
